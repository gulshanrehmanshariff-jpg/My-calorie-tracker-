MY CALORIE & FITNESS TRACKER — ANDROID INSTALLATION

This is a Progressive Web App (PWA) project. It is not a signed APK.

To install it on Android:
1. Publish the contents of this folder to a static HTTPS host (for example, GitHub Pages).
2. Open the hosted https:// address in Chrome on your Android phone.
3. Tap Chrome's three-dot menu, then "Install app" or "Add to Home screen".
4. Confirm. The tracker will appear as an app icon.

The app stores diary entries in this browser's local storage on this device.
Use "Export diary" regularly for a backup. Clearing browser data can erase entries.
For privacy, do not use a shared phone profile.
